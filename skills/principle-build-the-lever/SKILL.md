# Build the Lever

When work is repetitive, error-prone, or must be rerun or audited, encode it in
the smallest deterministic tool that performs or proves the operation. Make the
tool safe to rerun and easier to inspect than the manual work it replaces. Use
the tool as the artifact, not as the beginning of a framework.

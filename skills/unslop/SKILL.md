# Unslop

Use this procedure for prose artifacts before review. Keep routine conversation
clean while drafting rather than loading the full review catalog on every turn.

## Procedure

1. Identify the artifact, audience, purpose, and intended voice.
2. Preserve the original claims, evidence, and meaning.
3. Read `references/lachieh-voice.md`, `references/word-choice.md`,
   `references/punctuation.md`, and `references/patterns.md`.
4. Rewrite for directness, specificity, concrete actors, and the project's real
   terminology.
5. Remove every applicable pattern finding and apply the word-choice and
   punctuation rules.
6. Verify links, symbols, paths, counts, quotations, and attributions against the
   current artifact.
7. Read the result once for awkward or generated phrasing. Stop when each
   sentence earns its place.

## Completion

The revision preserves meaning, introduces no unsupported claim, uses real
project terminology, fits its audience, and has no applicable findings from the
references.

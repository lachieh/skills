# Prose review patterns

## Claims

- Remove puffery and promotional claims that lack evidence.
- Name the source behind an attribution or delete the attribution.
- Replace generic assessments with a fact, mechanism, measurement, or decision.
- Remove formulaic challenge-and-triumph framing.
- Remove conclusions that state no specific consequence or action.

## Language

- Cut filler without changing meaning.
- Reduce stacked hedging to the uncertainty the evidence requires.
- Use one name for one concept instead of cycling through synonyms.
- Use the natural number of points rather than forcing groups of three.
- Replace false ranges with the actual items being discussed.
- Prefer active voice when the actor matters.
- Replace weak verb and adverb pairs with the precise action or measurement.

## Structure

- Split a sentence when the reader must backtrack to parse it.
- Keep one thought or instruction in each sentence.
- Remove headings and labels that merely repeat the following sentence.
- Use numbered lists for sequences and bullets for unordered sets.
- Keep list items parallel.

## Conversation artifacts

- Start with the answer rather than an acknowledgement or chatbot opener.
- Remove praise that does not affect the answer.
- Remove generic invitations to ask more questions.
- State uncertainty, blockers, and recommendations directly.

## Verification

- Check that every link was read or produced.
- Check that every symbol, path, command, and count exists at the current state.
- Check that quotations and attributions match their source.
- Remove any sentence that could appear unchanged in an unrelated project.

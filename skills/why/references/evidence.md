# Evidence rules

Classify each conclusion by what supports it.

- **Direct.** A source explicitly states the intent or decision.
- **Supported.** Several independent sources converge on the conclusion without
  stating it in one place.
- **Inferred.** Evidence supports a reasoning step that no source states.
- **Speculative.** A possible explanation with weak or incomplete evidence.
- **Unknown.** The searched record does not answer the question.

Direct and Supported conclusions require precise citations. Inferred and
Speculative conclusions explain the reasoning chain and alternative readings.
Unknown conclusions name the searches performed and sources unavailable.

Do not use current code as evidence for its own motivation. Code comments,
tests, commits, and reviews can provide intent when they state it explicitly.

Treat a reason suggested by the user as a hypothesis. Search for confirming and
contradicting evidence before accepting it.

An empty search reports coverage. It does not prove that a decision was never
recorded.

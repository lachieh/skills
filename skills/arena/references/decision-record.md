# Arena decision record

## Artifact

Name the task and final artifact.

## Candidates

List each candidate, provider or direction, output path, and completion status.

## Criteria

Record the acceptance criteria and candidate scores.

## Selection

Name the selected base and the evidence behind the decision. Include the
independent judge's recommendation and explain any disagreement.

## Integration

List each integrated idea and its source candidate. List rejected ideas with the
reason they did not belong in the final design.

## Verification

Record the exact artifact verified, verifier independence, checks run, evidence,
and result.

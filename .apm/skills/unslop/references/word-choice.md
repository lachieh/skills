# Word-choice rules

## Never use

- `honest`
- `load-bearing`
- `seam`

Choose the concrete meaning instead. Depending on context, use accurate, direct,
candid, required, structural, boundary, interface, integration point, or the
specific mechanism.

## Replace in normal prose

These usually signal vague, promotional, or generated writing:

- `delve`
- `fostering`
- `garner`
- `interplay`
- `pivotal`
- `showcase`
- `tapestry` when abstract
- `testament`
- `underscore`
- `vibrant` when promotional

Replace them with the concrete action, fact, or result.

## Require specific evidence

These words can be valid, but they often conceal useful information:

- `crucial`
- `enduring`
- `enhance`
- `intricate`
- `significant`
- `quick`
- `simple`
- `easy`

State why something matters, how long it lasts, what improved, what makes it
complex, or the measured change.

## Usually remove

- `Additionally`
- `It is important to note`
- `In order to`
- `Due to the fact that`
- `Of course`
- `Certainly`
- `Great question`
- `I hope this helps`
- Generic conclusions about a promising future

These usually add structure or enthusiasm without information.

## Replace vague metaphors

- `bedrock`
- `endgame`
- `flywheel`
- `gold-plating`
- `north star`
- `tapestry`
- `wedge` when used as product jargon
- `evacuate` when code is merely moved
- `ratchet` when the mechanism has a clearer name

Name the actual mechanism instead.

## Allow literal technical use

Do not reject a technical term merely because it is sometimes vague:

- `vector`
- `primitive`
- `harness`
- `surface`
- `substrate`
- `locus`
- `modality`
- `paradigm`
- `scaffold`
- `ratchet`

A test harness, vector index, graphics surface, language primitive, or monotonic
ratchet names a concrete thing. Review the use, not only the token.

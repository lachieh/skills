# Investigator prompt

Investigate one assigned evidence source for a historical question. Gather
material for a separate synthesis agent. Do not write the final narrative.

## Work

1. Start from the supplied code anchor, identifiers, and decision window.
2. Search broadly enough to find alternate terminology, then narrow.
3. Read complete discussions rather than titles and snippets.
4. Follow links within the assigned source.
5. Record cross-source links as leads for another investigator.
6. Capture exact quotations when wording carries the rationale.
7. Record contradictions and searches that returned no relevant result.

## Return

- Source and access method.
- Queries, date ranges, and items inspected.
- Direct evidence with author, date, and citation.
- Indirect evidence with the reasoning it permits.
- Contradictions.
- Gaps and unavailable material.
- Cross-source leads.

Do not infer intent from current mechanics or silently replace the target with a
related decision.

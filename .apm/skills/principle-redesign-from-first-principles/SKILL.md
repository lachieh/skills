# Redesign From First Principles

Integrate a new requirement as if it had always been part of the system. Reshape
models, boundaries, APIs, and ownership so one coherent design expresses both
existing and new behavior. Remove accommodations whose only purpose is
preserving the pre-change shape. Judge the result independently of the migration
path used to reach it.

# Review 26: Technical Writing

Status: approved and implemented

Source: `tmp/pstack/skills/technical-writing/SKILL.md`

Implementation: `.apm/skills/technical-writing/SKILL.md`

## Verdict

Keep the procedure with a compact main workflow and disclosed references for
document modes, developer style, and controlled language. Let Unslop own voice,
word choice, punctuation, and general prose findings.

## Approved procedure

1. Identify the artifact, reader, task, and outcome.
2. Inspect source material and repository terminology.
3. Select a documentation mode where applicable.
4. Outline around reader questions and actions.
5. Draft with the technical-writing references.
6. Apply Unslop.
7. Run safe commands and examples.
8. Verify every factual reference.
9. Review from the reader's starting context.

## Removed

- Diataxis requirements for pull-request descriptions and commit messages.
- Arbitrary sentence word limits.
- Repository-independent snippet formatting.
- Absolute bans already owned by voice and punctuation rules.
- Duplicate Unslop rules.
- Product interface copy.
